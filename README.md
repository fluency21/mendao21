# 每日看门道 · AI 资讯五层解码门户

把每天刷屏的 AI 资讯，从「看热闹」变成「看门道」。

一个纯静态的单文件站点生成器：读取本地 markdown 情报库（日报 / 专题 / 主题索引），一键构建出产品化的团队共读门户。

## 功能

- **五层解码卡片**：每条资讯按「说人话 → 概念扫盲 → 商业逻辑 → 行业信号 → 与我何干」五层结构化呈现
- **页内 AI 深挖（BYOK）**：读者填入自己的 OpenAI 兼容 API Key（仅存浏览器 localStorage），即可对任意条目流式深挖、多轮追问
- **按我的行业看「与我何干」**：读者自定义行业/岗位身份，AI 按读者视角重新解读启发
- **标题搜索**：即时检索全部条目标题，点击跳转当期
- **分类索引**：主题横铺筛选，条目可跳回对应日报
- **情报众筹 + 需求池**：对接腾讯文档收集表，读者可投稿资讯、把启发转化为需求卡
- 深浅色自适应（可手动切换）、移动端优先、单文件无依赖

## 目录结构

```
看门道门户/
├── build.py          # 站点生成器（Python 3，仅标准库）
├── docs/
│   └── index.html    # 构建产物（GitHub Pages 直接托管此目录）
└── README.md
```

## 内容目录约定

生成器默认读取 `../AI情报知识库`，结构如下：

```
AI情报知识库/
├── 日报/YYYY-MM-DD.md    # 每日资讯，条目按 ## N. 标题 组织，正文含 **说人话**：等五层标签
├── 专题/*.md             # 深度专题（可选）
└── 索引.md               # 主题索引，## 主题名 + - [MM-DD] 条目
```

## 本地构建

```bash
python3 build.py
# 或指定路径
python3 build.py --content /path/to/AI情报知识库 --out ./docs
```

## 部署

- **GitHub Pages**：仓库 Settings → Pages → Source 选 `docs/` 目录即可
- **任意静态托管**：把 `docs/index.html` 上传到 Vercel / Netlify / EdgeOne Pages / 对象存储均可，单文件零依赖

## 页内 AI 深挖配置（BYOK）

1. 点页面右上角 ⚙ 打开设置
2. 填入 OpenAI 兼容端点（默认 DeepSeek `https://api.deepseek.com/v1`，模型 `deepseek-chat`）
3. Key 仅存你自己浏览器的 localStorage，不经过任何服务器

> 注意：浏览器直连要求 API 端点允许跨域（DeepSeek 官方端点支持）。若遇到跨域拦截，换用支持浏览器直连的端点，或自建一层轻量代理。
